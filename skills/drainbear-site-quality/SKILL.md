# 通渠熊網站改版

適用於 React／Vite／Express／Sanity 的通渠熊網站；使用現有 checkout，不另建 worktree，除非使用者要求。

1. 讀取目前任務、git status、相關頁面及共用元件；保留已有使用者變更。
2. 按任務使用以下專案技能：
   - [品牌與行銷](../drainbear-marketing/SKILL.md)
   - [自然文字與行文規範](../drainbear-writing/SKILL.md)
   - [元件、切版與除錯](../drainbear-interface/SKILL.md)
   - [SEO、AEO與無障礙](../drainbear-search-quality/SKILL.md)
3. 從共用元件和單一設計來源處理問題，避免新增按改版日期疊加的 CSS 覆寫。
4. 先完成可獨立進行的工作。競品讀取、CMS或資料庫遭封鎖時，留下實際回應及未驗證範圍，不以假資料聲稱已通過。
5. 執行型別檢查、相關現有測試、應用程式編譯及瀏覽器操作；以320、390、768、1024、1440px驗證必要版型。
6. 保存改版報告、已驗證行為及仍須外部存取的工作。按本次結果更新技能；不要將一次性的網路故障寫成永久限制。
7. 聯絡點擊及WhatsApp外跳與實際收到查詢、報價、接納及完工分開記錄。後者只由客服或接收系統確認；維護模板見docs/customer-journey-refresh.md，不用假業務事件填補外部存取缺口。

此技能及四個子技能為本專案自行建立，不代表已安裝同名的第三方技能。
