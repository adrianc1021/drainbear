# 自然文字與行文規範

- 首頁及聯絡文案可用自然香港用語，例如「塞廁所」「傳相片」「先了解點處理」；技術說明和安全指引使用清楚的繁體中文。
- 首頁與服務選擇卡以短標題、一句重點及圖片讓客人掃讀；資料完整不等於全部預設展開。不在每張案例卡重述摘要，完整紀錄放在案例詳情。以實際手機預設可見文字及圖片成功載入核對減字成效，不能把減少CSS字級當作精簡文字。
- 一段回答一個實際問題。先給答案，再解釋限制、需要甚麼資料及下一步。
- 每頁只有一個H1；H2描述讀者要解決的問題，H3處理細項。不為字體大小跳級。
- 標題應具體，例如「常見通渠收費參考」，避免「全方位專業解決方案」「重新定義」「賦能」「極致」「科技斷症」等空泛表述。
- 不在相鄰版塊重複「先報價後動工」和完整聯絡說明；保留首屏、收費／流程及頁尾必要位置。
- 2026-10-16 最新業務方向：所有通渠服務 HK$300 起報價，使用 shared/pricing.ts；首頁及服務入口直接突出起步價、服務賣點及 WhatsApp 查詢，不堆疊額外解釋。起步價不改寫成所有工程固定總額，也不自行新增免費、不成功不收費或效果保證。修改既有價格文章須同步網站修訂及實際更新日期。
- 保留已有的事實與服務條件；不自行加入客戶證言、比較性保證或虛構工程證據。
- AEO答案直接、可獨立理解；可見FAQ與JSON-LD須由同一份答案資料輸出。
- 最後逐句朗讀：像公司會對客人說的話嗎？能否減少一句而不失去必要資訊？

執行時檢查實際頁面文字，不只檢查README；避免把內部開發／部署流程放入產品頁面。

- 文章共用 CTA 使用「WhatsApp 查詢」，不以「免費報價」作未確認的業務承諾。更新共用入口後，逐篇核對公開文章的 CTA；內容中的歷史政策不可一併盲目取代。

- 整理通渠消費爭議報道時，使用自行撰寫摘要、原始報道日期及原文連結；逐項區分拘捕、當事人說法、網民轉述及裁決。原文匿名或只列暱稱時，不補全公司身份；歷史個案金額不當成現時價目，示意圖不作新聞現場證據。
