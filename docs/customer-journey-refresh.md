# 通渠熊：客戶路徑、搜尋與查詢重整

日期：2026-10-08。

## 本輪實作

- 保留藍白紙藝品牌、置中大標題、首屏電話及 WhatsApp。
- 首頁只保留一個客群／問題選擇區，真實施工案例提到服務安排前。
- `/customers/residential`、`/customers/restaurants`、`/customers/property-management` 各有不同的現場資料清單、適用服務、案例及 FAQ。
- 原 `/guide` 網址保留，改為現場查詢與報價指南。移除主要指南的數字價格表及 Offer 價格資料；FAQ、地區及流程不再突出免費／不成功不收費條款。歷史 CMS 文章未批量改寫。
- 原維護中的表格版塊改為 `InquiryContactPanel`，直接使用共用電話／WhatsApp 入口及事件；沒有啟用未驗證的表單接收或發送虛假收件確認。
- 八項服務連到經核對的施工紀錄，案例再連回服務／FAQ。相關操作與同類施工寫清楚，不把家居去水案例當作隔油池清理，或把短片當作完工結果。
- 服務及客群頁加入段落目錄、FAQ 固定題目連結。導覽精簡，原有內容仍可從頁尾到達。
- `/about#company-facts` 提供與 CMS 同源的公司名稱、電話、服務對象及安排。知識檔的 `companyFacts.source` 指向該公開來源，建置核對名稱及電話。
- 公開知識抽取排除 video 內的非顯示後備文字、隱藏客群面板及標記的工具內容。FAQ 答案仍由實際頁面與 schema 核對。
- `answerCatalog` 按相同問題整理答案與來源；`coverage.answers` 是條目數，`coverage.uniqueQuestions` 是按移除空白後的題目計算，沒有把不同措辭當作語義相同問題。

## 收費內容規範

按使用者要求，減少收費條款及統一價格的篇幅。網站以「傳送現場資料、了解處理方向及報價」引導；沒有固定價、免費或成功保證。保留現場檢查及確認方案的必要說明，毋須每個版塊重複。

要更新歷史 CMS 文章的現行業務政策，需逐篇確認文章用途、日期及公司資料，再透過有權限的 CMS 編輯；不在顯示層以全站字串替換掩蓋原始內容。

## 點擊、外跳與實際查詢

`whatsapp_click`、`phone_click` 表示點擊；`whatsapp_handoff` 表示一次性網站外跳流程。它們都不證明應用程式成功開啟、訊息傳送、電話接通或公司收件。`/thanks` 只提示完成傳送及提供替代聯絡。

實際收到查詢、有效查詢、提供報價、接納及完成工程需要客服記錄或有權限的接收系統確認。網站沒有該外部回傳，不自動生成這些業務事件。起步可使用 `lead-register-template.csv`；一宗問題以同一匿名查詢 ID 追蹤，電話及 WhatsApp 重複查詢合併。分析事件不傳客人訊息、電話或完整地址。

現有 Google Ads 點擊轉換保留，沒有登入更改主要／次要轉換；帳戶負責人取得有效查詢紀錄後再調整。內容互動 `case_click`、`case_video_start`、`case_video_progress`、`case_video_complete` 只送分析事件，不送 Ads 轉換；影片中點事件是播放位置跨過 50%，可以受跳播影響，不代表實際看足一半。

## 真實素材與地區證據

五段影片的日期、地區及完整完工結果尚未獲提供，維持空白。上傳檔名不是工程日期。地區頁不加入未確認的工程或分店；新的服務關聯均在 `shared/caseServiceRelations.ts` 審閱。案例網址變動須同步連結、轉址及原始資料。

兩個原有 CMS 案例的地區為破折號佔位資料；顯示及結構化資料視為未提供，不生成地理聲稱。地區頁已接上按明確地區匹配的案例模組，當有真實位置才顯示，當前不虛構當區證據。

## AEO 營運工作流

使用 `ai-citation-review-template.csv` 的固定問題作每月樣本。記錄日期、平台、模型／版本、搜尋設定、語言／地區、是否提及、引用來源及事實錯誤。使用未提示品牌的新對話；記錄失敗或未執行，不填作零次推薦。固定樣本不是市場推薦率。

每次確認公司資料後，更新 CMS 或相應受控來源，再完整建置，使公開頁、schema、知識檔同步；索引生成時間不能當成文章更新日期。Search Console、GA4、商家及外部 AI 平台帳戶本輪沒有已驗證的可用權限，不能宣稱完成排名／推薦／成交基準。

## 驗證

發布前執行型別、現有測試、完整建置、AEO／sitemap／SEO、路由、轉換及瀏覽器驗收；覆蓋 320、390、768、1024、1440px。額外檢查客群切換、選地區的預填訊息、查詢頁重試、服務↔案例連結、公司資料來源及影片分析去重。
