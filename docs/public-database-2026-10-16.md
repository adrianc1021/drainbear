## 功能及呈現

- 搜尋事件、金額、發布機構及報道中的稱呼；多個字詞同時比對，金額搜尋接受逗號及 $。
- 官方紀錄／消委會個案／傳媒報道分類，另按臨場加價、售後跟進、身份疑問等類型篩選，按首刊日期排序。
- 搜尋條件存在網址；支援清除、空結果及瀏覽器返回。排序同時改變 DOM 順序，沒有只以 CSS 重排視覺。
- 每筆有固定 `#record-…` 連結，能直接展開原生 details；若條件擋住指定紀錄，會清除條件再展示。
- 預設所有紀錄、摘要、詳細內容及來源都在預渲染 HTML。關閉 JavaScript 時隱藏搜尋／快速篩選，全部紀錄及原生收合仍可閱讀。
- 開放式分隔行，沿用現有字體、色彩、焦點及收合模式；沒有重複卡片或新增裝飾圖。手機標題按語意分行，提交搜尋後定位到結果。
- 方法及更新範圍寫明人工核對；補充、更正或回應可經原有公司聯絡方法提供來源，不會自動公開來稿。沒有新增未驗證表格、外部聯絡或自動爬網聲稱。

## 實際檔案

`client/src/lib/consumerAlerts.ts` 是來源、紀錄及純搜尋／排序邏輯的單一維護來源；`consumerAlerts.test.ts` 驗證來源完整性、唯一身份鍵、組合搜尋、排序與非修改式處理。

`client/src/pages/ConsumerAlerts.tsx` 提供獨立 CollectionPage、ItemList、搜尋篩選、原生來源連結、回應與範圍、官方入口及方法。沒有 Review、評分或涉事商戶 LocalBusiness schema。

`client/src/styles/brand-system.css` 加入局部 `.consumer-database` 樣式；`App.tsx` 及 `routePrefetch.ts` 使用 lazy route，不把整份資料放入首頁首載模組。`shared/publicRoutes.ts` 的 RESOURCE_ROUTES 同步 Express 靜態路由、預渲染及 Sitemap；lastmod 使用同一資料修訂日期。

相關搜尋品質及介面技能保存此維護／驗證模式。

`Layout.tsx` 增加頁腳入口；兩篇公司選擇／防騙文章加入資料庫連結。原有文章網址、封面、配圖、canonical、發布日期及首頁設計保留。

`.impeccable/surfaces/consumer-alerts.md` 保存 Read 介面及收錄方向；沿用既有設計世界，沒有宣稱首頁歷史 strict-comp gate 已通過。

## 維護
