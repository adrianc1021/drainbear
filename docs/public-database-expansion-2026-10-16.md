# 通渠公開資料庫：報道擴充

2026-10-16。正式頁面：https://drainbearhk.com/consumer-alerts

## 實際內容

由原先9篇來源擴充至34篇：32篇相關報道、節目整理、供稿專欄及轉載，另有2篇官方資料。25篇新增原文均成功讀取 HTTP 200，與原先同日核對的9篇組成完整來源清單。並非30宗獨立投訴或30間商戶；同稿及跨平台轉載保留資料性質與說明，沒有以篇數暗示獨立採訪數。

12組紀錄包含原有8組，以及2024年網民加價經歷、2025年港漂鋅盤 $700 至 $18,000、2025年廁所倒灌 $55,000 及同一裝修佬專欄的跨平台資料組。後者只作相關專欄資料，不額外認定受害人或事件數。新紀錄保留當事人說法、師傅未接電話、未有正式回應及未附裁決等實際狀態。

新增來源涵蓋星島頭條、on.cc東網、東方日報、點新聞、am730、巴士的報、香港01、東張、UHK、裝修佬／裝修學院、新假期、東方新地、New Monday、SundayKiss、經絡及美聯專欄。沒有把供稿平台寫成獨立新聞採訪。

新增「逐篇查閱報道及官方資料（34篇）」原生收合目錄，逐篇列標題、發布機構、日期、資料性質、原文、摘要及相關紀錄。沿用既有元件及開放式文字版面，沒有新增新聞相片或轉載全文。目錄可經 `#report-sources` 或 `#source-來源id` 直接開啟；關閉 JavaScript 仍有全量資料及原生收合。

搜尋涵蓋新增發布機構、來源標題、日期及摘要。單一來源可能同時報道多個消委會個案，因此純數字／金額只比對紀錄本身，避免搜尋 $58,000 時把同篇文章另外的漏水個案也當成該金額。

## 日期與來源核對

採原文日期，不用搜尋摘要代替。香港01港漂報道原刊2025-05-22，2025-05-23是更新；經絡正文標示2025-02-21，文中的2024-12-28是節目日期；新假期／東方新地採頁面顯示2026-10-02，香港頭條採頁面顯示2026-10-03。柳俊江資料組因新增兩篇2023-01-04刊載頁面，組日期改為1月4日起；各篇原日期分別保留。

Google一般搜尋回傳人機驗證，沒有繞過。改以可用新聞索引發現網址，再開啟原站閱讀正文。晴報登入頁和節目預告未用來湊數；點新聞核對的是正文，不是頁面AI摘要。原始快照留在工作區，版本庫只保存自行撰寫摘要、網址及SHA256。34份快照校驗均吻合，來源與各組對應見 [sources.json](public-database-expansion-2026-10-16/sources.json)。
