# 首頁第二段：快速查詢

2026-10-09（香港時間）。首頁首屏之後使用同一個 HomeServiceFinder，整合住宅、食肆與物業分類、服務選單、可選地區及 WhatsApp 查詢，不另建重複的查詢版塊。

服務選單只顯示所選分類的服務，另有「未確定，先查詢」。服務旁顯示對應的 AI 紙藝插圖；未確定時使用問號示意。每個分類記住自己的選擇，地區跨分類保留。WhatsApp 預填訊息包含服務、地區及該類客戶的現場資料提示，保留共用查詢交接與追蹤機制，點擊不代表已收到訊息。

完整 AI 圖片與服務頁入口放在「睇圖了解處理方法」原生收合區。搜尋引擎可從 HTML 找到連結，鍵盤可開合，關閉 JavaScript 仍可閱讀住宅圖片入口。預設版面先展示查詢操作及精簡倒灌安全提示，之後是真實案例和上門安排。

手機上服務和地區垂直排列，桌面並排；CTA 使用真實 WhatsApp 品牌圖示，支援 hover、active、focus-visible 及減少動態偏好。

已核對 TypeScript、完整正式建置及 SEO／AEO／sitemap／影片檢查；40 個頁面與尺寸組合；三類客戶在 320、390、768、1024、1440px 下的全部服務、未確定、可選地區、AI 場景、服務連結與選取保留；原生收合鍵盤操作；實際 WhatsApp 跳轉至預填視窗及交接頁（攔截測試，沒有傳送訊息）；首頁五種尺寸 axe。

同一檢查工具的住宅分類區域截圖：390px 寬時預設高度由 1,359px 減為 891px（約 34%）；1440px 寬時由 912px 減為 811px。這是該區的預設顯示高度，完整圖片入口展開後會增加高度，不代表內容被刪除。
