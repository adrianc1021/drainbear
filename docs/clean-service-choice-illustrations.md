# 首頁服務選擇：乾淨 AI 插圖

2026-10-09（香港時間）。「由眼前嘅問題開始／塞邊度？搵啱處理方法。」中的住宅、食肆及物業所有服務選項使用 AI 藍白紙藝白熊插圖。八個場景分別對應坐廁、鋅盤、浴室去水、倒灌管道示意、隔油池、高壓洗渠、照喉及主渠沙井，避免讓客人先看到污水或施工近鏡。

素材由 image_gen 生成，來源 /workspace/generated_images/exec-b538b2e9-0390-4690-8e4f-cc6a86888e6d.png，原始檔保留。部署為 client/public/images/drainbear-services-ai.webp，1536×768，161,546 bytes，SHA-256 `a14ce3b15c8062bef1c123f6f62c19d7b5cfb357d15bafe08e7585c19d817b9e`。WebP 只作網站格式與尺寸最佳化，ServiceIllustration 透過 CSS 顯示四欄兩列中的相應場景並保持圖像比例。共用一份素材，切換分類不需載入八個獨立檔案。

插圖的無障礙名稱表明 AI 示意用途，圖片不聲稱為客戶工程。ServiceIllustration 不以真實照片作缺少素材的替代。首頁分類、服務目的地、地區選擇、WhatsApp 預填訊息及既有引導順序保持其功能。

核對：pnpm check、pnpm build、scripts/verify-visual-reading.mjs。瀏覽器檢查包含五種尺寸下三個分類的切換、全部服務圖像來源及對應場景、圖片解碼、有效服務連結、版面與 WhatsApp 接續；首頁另做五種尺寸 axe 核對。
