# 手機首頁閱讀整理

使用 drainbear-interface、drainbear-writing 專案指引。參考錦明的設備／問題／收費分類、百達的家居服務與常見問題、日榮的客群及範圍分工，改寫成原創服務摘要，沒有使用競品年資、評價或效果承諾。本次錦明HTTP200；其他來源如即時存取受限，沿用本次對話較早保存的完整頁面。

首頁六章各增加一段直接可讀摘要，完整原文與連結保留在原生 details HTML。四類症狀的服務連結直接顯示；六項目錄、三張配圖、首屏白熊、報價及聯絡功能保留。手機調整標題、段距與工具圖文排列，至少16px正文，48px目錄及收合入口。不改title、canonical、網址或FAQ資料。

390×844px、Chromium、減少動態、所有配圖成功解碼下，詳解預設高度由7144px變3388px，減少52.6%。這是閱讀長度改善，不是速度或SEO排名測試。完整正文可按章展開，關閉JavaScript仍可原生操作。

TypeScript及完整建置通過。320／390／768／1440px無橫向溢出；六章鍵盤開關、內部錨點自動展開、無JavaScript原生收合、axe AA檢查通過。無JavaScript依次開多個長章節的第一次自動點擊遇到動畫期間定位不穩，使用減少動態條件完成穩定驗證，沒有以移除內容來繞過。既有手機回歸檢查通過：首屏／固定聯絡列、服務橫掃及縱捲、鍵盤、真實影片播放與離開暫停、收合焦點。未測實體手機及Safari。
