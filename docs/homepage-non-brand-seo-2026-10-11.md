# 首頁非品牌搜尋優化

日期：2026-10-11（香港時間）。正式首頁：https://drainbearhk.com/。

## 問題及改動

首頁原有品牌標題、服務選擇器及施工短片，但常用服務入口需展開或切換分類，正文對整體服務範圍的說明較少。本次加入「香港通渠服務」段落及簡短介紹，並提供五個直接可見的服務入口：坐廁、鋅盤、浴室、隔油池、主渠及沙井。

優化方向為香港通渠、通渠服務等非品牌服務查詢。詳細症狀與地區需求繼續由既有服務及地區頁承接；維持現有首頁 title、description 和 H1，避免剛更新便頻繁換標題。

新增入口使用既有 service_click 事件，cta_location 為 home_common_services，記錄服務及目的地。沿用現有電話及 WhatsApp 查詢流程，按鈕文案統一為「24小時通渠查詢」，實際上門時間另行確認。

首頁保留三段施工操作短片，增加一段簡短說明及兩個附完工測試的公開工程入口。工程事實來自已發布案例內頁：

- /cases/home-basin-grease-buildup-cleaning：拆喉清理後進行連續放水測試，檢查去水及接駁滲漏。
- /cases/school-rainwater-drain-high-pressure-cleaning：高壓清洗後進行排水測試，觀察渠口水位及積水。

兩宗工程的實際地區沒有公開，沒有加入或推測地區；三段操作短片也沒有被改寫成已完工驗收案例。

## 載入資產

- 首頁服務圖改用同一 AI 圖稿裁切的 224／384px WebP，按尺寸選擇。首頁不再載入整張 1536×768 服務插圖；其他頁原有完整圖片保持可用。
- 192px 頁首／浮動品牌圖由 67,640 bytes 的 801×801 PNG 改為 9,152 bytes 的 192×192 WebP，檔案減少約 86%。favicon 保留原有格式。
- 首頁分享圖由 5,000×2,625 PNG（3,200,826 bytes）改為 1,200×630 JPEG（103,374 bytes），檔案減少約 97%；分享圖不算作首頁內文載入量。
- 移除全站 Material Icons 字體 CSS，原有唯一使用處改用現有 lucide SVG。
- 移除首頁重複的 WebPage schema，保留共用 SEO 元件的頁面節點，以及與可見答案同源的 FAQ。

檔案減重不等於已證明真實使用者 Core Web Vitals 改善，需以現場數據核對。

## 非品牌成效量度

本次沒有讀取登入後的 Search Console 報表，沒有目前排名／CTR 基線，亦沒有聲稱搜尋表現已提升。

1. 搜尋類型選「網頁」，頁面完全等於 https://drainbearhk.com/。
2. 查詢選「不符合規則運算式」，排除品牌：通渠熊|drainbear|drain\s*bear。
3. 查看香港／手機；如需整體數據，另保留未限裝置的相同篩選。
4. 匯出改版前最近 28 個完整資料日作基線，記錄期間、篩選、曝光、點擊、CTR、平均排名及主要查詢。
5. 改版後每週記錄相同篩選。累積 28 個完整資料日後再比較等長期間；不要使用最近 24 小時的波動判定效果。
6. 排名已在前十但 CTR 低，可再測試標題；排名較後，優先完善與查詢相符的內容、案例及相關連結。
7. 另看 home_common_services 的 service_click、電話／WhatsApp 點擊及實際收到的查詢。點擊不是收到查詢或成交的證明。

Google 端的 sitemap 狀態及重新索引要求仍需在已驗證的 Search Console 資源中操作；提交要求不保證收錄或固定排名。
