# 圖片優先與精簡閱讀改版

2026-10-09（香港時間）。客人原本要跨過服務說明才看到施工照片，服務內頁又同時展開症狀、成因、流程、準備事項及所有答案。新版把真實案例放在首頁第二段，圖片配短標題作為選擇入口，讓詳細內容按需要展開。

## 改動

- 保留藍白品牌、置中大標題、首屏电话和真正 WhatsApp 品牌圖示。首屏只留一句行動說明；首頁流程以四張短卡顯示。
- 首頁優先展示喉口檢查、坐廁疏通及戶外渠口三種真實施工短片。案例卡保留照片、名稱、片長和入口，完整摘要與證據在案例詳情。
- 首頁、服務目錄、客戶服務入口和場所分類使用 ServicePhoto 與 serviceVisuals。四項服务使用現有真實影片縮略圖，其餘沿用已有服務示意素材；圖片描述不將示意圖聲稱為真實工程，也不將案例聲稱為未確認的地區工程。縮略圖按版型裁切，完整影片保持原樣。
- 八個服務內頁提早展示案例；適用情況以短標籤顯示，症狀、成因、流程詳情、資料清單及 FAQ 預設收合。18 個地區內頁亦收合背景、常見情況及 FAQ，並加入可點擊的實際施工照片。
- 住宅、食肆與物業客戶頁加入圖片入口、提早展示案例。共用查詢區以三項圖示提示資料，完整資料清單可展開，預填 WhatsApp 訊息仍包含相應客戶所需資料。
- 相關案例支援從已發布 CMS 紀錄載入實際封面。建置與核對等待 CMS 完成；所有圖像必須成功解碼，不能以空白色塊視為照片已顯示。
- 共用 AnimatedDisclosure 支援直接答案錨點及 hash 變更，自動展開相應答案。沿用原生鍵盤、關閉時即時 inert、減少動態及無 JavaScript 操作。完整文字、107 個 FAQ 答案與來源連結仍在預渲染 HTML，並非僅放在不可見的搜尋資料內。

## 390px 手機量度

預設文字量為 main 內不含空白的文字字元，排除收合內容、非當前場所、裝飾／輔助隱藏文字；這是掃讀負擔的代理指標，不是客戶行為或轉換率。舊版由正式網站讀取，新版由同一瀏覽器、900px 高視窗、相同 CMS、減少動態及圖片解碼完成後讀取。照片數不計收合或非當前場所。

## 已驗證

TypeScript 與完整正式建置通過；71 個可索引網址、107 個 FAQ 答案及五段真實影片的 AEO、sitemap、SEO 檢查通過。現有網站品質核對涵蓋 61 條路徑、100 項響應式檢查及 41 次 axe 審查。客戶旅程與地區／頁腳核對亦通過。

新增 scripts/verify-visual-reading.mjs，以 320、390、768、1024、1440px 核對八種頁面，40 項檢查均無圖片載入失敗、橫向溢出或缺少 WhatsApp 標誌；額外核對答案錨點、hash 變更、展開收起後立即 Tab、資料清單、無 JavaScript 閱讀及 WhatsApp 接續。WhatsApp 測試攔截外跳，沒有發送訊息；此核對不代表實際收到查詢或成交。

可在已完成正式建置的本地伺服器（PORT=4580）執行 `NODE_USE_ENV_PROXY=1 node scripts/verify-visual-reading.mjs`；正式站核對可指定網址，並用 READING_QA_OUTPUT 指定證據目錄。
