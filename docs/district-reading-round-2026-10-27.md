# 地區搜尋第二輪：文章入口與查詢資料

依據：使用者提供的 2026-09-28–2026-10-25 Search Console 報表。北角、大坑／銅鑼灣、觀塘及大埔有曝光而點擊少；資料為全地區查詢匯總，沒有查詢×頁面關聯，亦早於 10/26–27 修訂，不能證明近期版本失效。

## 改動

四篇既有文章在「相關服務與延伸資料」加入有上下文的地區指引，保留原正文、封面及發布日期：

- 坐廁應急指南 → 北角／炮台山水位及異物資料。
- 浴室頭髮防塞 → 大坑浴室相連喉管與入口。
- 隔油池指南 → 觀塘工廈食堂設備及下游管段。
- 村屋雨季排水 → 大埔雨天積水及進場安排。

連結由 `ARTICLE_DISTRICT_READING` 維護，沿用資源清單的去重及原有標籤優先規則。修訂日期只影響這四篇文章，CMS／靜態後備／列表／Sitemap 使用相同日期邏輯，保留較新的原稿日期。

北角、銅鑼灣、觀塘及大埔新增獨立 `inquiryMessage`，首屏和頁尾沿用 ContactActions 的 WhatsApp URL 與既有追蹤。訊息提示地點、症狀、相片及適用的進場資料，沒有自動發送；其他地區使用原有後備訊息。頁尾保留客群選擇。

沒有改動近期標題／描述、建立新地區頁、聲稱當區工程紀錄，或新增排名／到場承諾。污水倒灌頁已具備相應內容及入口，本輪保留。

## 驗證範圍

執行 TypeScript、完整測試、CMS 建置、SEO／Sitemap／AEO／解答驗證。八頁在 320／390／1440px 檢查單一 H1、canonical、robots、無溢出；檢查每條新連結只出現一次、目標頁與錨點存在。四區 WhatsApp 首屏／頁尾訊息、電話連結及無 JavaScript 正文／連結須一致。

此輪是內容導覽及查詢準備改善，不能直接推論 Google 排名或 CTR 已上升。沿用固定查詢群及 28 日觀察方式，分開記錄自然搜尋點擊與實際查詢。
