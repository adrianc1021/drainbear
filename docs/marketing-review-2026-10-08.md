# 通渠熊品牌與行銷方案

日期：2026-10-08。依據目前網站、公開 CMS 記錄及使用者指定的 https://plumberhk.com/。此文件記錄實際觀察；不代表已核實 Google 排名或競品的服務承諾。

`plumberhk.com` 首頁 HTTP 200，HTML title 顯示「文記專業通渠公司」，canonical 指向 `https://mankeedrainage.hk/`。這是回應中的網站資訊，不能據此證明兩個網域的擁有權。

原始首頁留存在 `/workspace/drainbear-review/plumberhk-home.html`。首頁為需要JavaScript的網站；其 `cdn.wegic.ai` 腳本目前被代理拒絕（CONNECT 403），所以沒有聲稱已驗證其完整版面或手機操作。

Google查詢「香港 通渠」（google.com）及「香港通渠」（google.com.hk，hl=zh-HK）回傳HTTP 200，但內容只有JavaScript重導及回饋入口，沒有可判讀的搜尋結果。實際搜尋位置未受控制。不能確認榜首、廣告／地圖／自然結果次序，也沒有足夠證據比較多家排名領先公司。恢復可讀搜尋結果後，應再核對「24小時通渠」「通渠收費」及地區詞，保存日期、位置和實際結果，補充競品表。

## 品牌審查與定位

定位：香港住宅、食肆及物業渠務；先了解問題、先報價、確認後動工。

舊版的問題是首頁過長、同一承諾重複出現、十二份CSS覆寫導致頁面不一致，以及部分形容詞取代了具體說明。本次改為深藍、淺灰及WhatsApp綠的共同視覺；橙色只作少量標示。工程圖像標示用途；真實案例保留現有日期、地區和處理記錄。文字直接回答位置、症狀、工具、報價因素與下一步。

| 客群／需要                                 | 入口與相關內容                            | 查詢時應提供                               |
| ------------------------------------------ | ----------------------------------------- | ------------------------------------------ |
| 住宅住戶：坐廁塞、鋅盤去水慢、浴室積水     | 坐廁／鋅盤／浴室服務、收費指南、診斷、FAQ | 地區、去水位置、出現多久、相片或短片       |
| 食肆及商舖：油脂堵塞、隔油池、營業安排     | 隔油池清理、高壓洗渠、流程、工程案例      | 場所、受影響範圍、可施工時段、隔油設施情況 |
| 業主及物管：主渠、沙井、多處倒灌、反覆淤塞 | 主渠及沙井、CCTV、當區頁、相關文章        | 受影響單位／樓層、既有處理記錄、共用渠位置 |

這些入口連到既有且有具體內容的頁面，不增加服務乘地區的關鍵字門頁。

## 可执行的推廣計劃

1. 上線前：核對正式CMS電話、WhatsApp、起步參考價、文章及案例；確認實際24小時查詢安排。使用本次建置、sitemap及手機驗證結果。
2. 上線後首週：透過Search Console檢查正式canonical、sitemap接收和索引情況；用現有GA4／Google Ads事件觀察電話、WhatsApp及診斷轉交。此工作沒有部署，也沒有存取Search Console或廣告帳戶。
3. 第二至四週：按客群及服務頁比較有效查詢，將常見報價問題補到對應FAQ；由真實工程資料補案例。現有25條文章路由及2個已發佈案例已提供內容基礎，不另外生成重複文章。
4. 收集實際查詢後才設定成效基準。聯絡點擊、WhatsApp開啟及thanks頁代表聯絡流程事件，不能直接計作成交。不要在沒有數據時設定轉換提升百分比或排名保證。

待核實：完整競品介面、其他自然搜尋領先公司、正式網站索引、搜尋曝光與真實詢盤／成交數據。
